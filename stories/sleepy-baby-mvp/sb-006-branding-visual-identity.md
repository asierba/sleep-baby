# SB-006: Branding & Visual Identity

## Description
Replace default Expo placeholder assets with Sleepy Baby branding: custom app icon, splash screen, and display name.

## Acceptance Criteria
- App icon, adaptive icon (Android), and favicon (web) are replaced with Sleepy Baby branding
- A custom splash screen with the app logo displays on launch
- The app display name is configured as "Sleepy Baby" in app config
